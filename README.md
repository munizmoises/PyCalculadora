# PyCalculadora 🧮

Uma calculadora desktop simples e responsiva desenvolvida em Python utilizando a biblioteca gráfica Tkinter. O projeto conta com ajuste automático de inicialização para abrir sempre perfeitamente centralizado na tela do usuário.

## 🛠️ Tecnologias Utilizadas

*   [Python 3.11.9](https://python.org)
*   [Tkinter](https://python.org) (Biblioteca nativa do Python para interfaces gráficas)
